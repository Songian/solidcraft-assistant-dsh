# GB 标准知识（0.0.1 子集）

来源：`knowledge/standards/GB.json`。所有条目 `verification.status = unverified`；未经 P3 官方目录核对，**不得**在报告中作为“符合 GB”的依据。

## 选择

1. 在 brief 写 `intent.standard: "GB"`；
2. 默认未注线性/角度公差等级 `m`，除非 brief 明确其它等级；
3. 投影第一角；GB/T 14692（版本待核）一般规定第一角，图面需投影符号。

## 四类数值规则

| 主题 | 标准 | 关键内容 |
|---|---|---|
| 未注线性公差 | GB/T 1804-2000 | m 级：0.5–3/3–6 → ±0.1；6–30 → ±0.2；30–120 → ±0.3；120–400 → ±0.5 mm |
| 未注角度公差 | GB/T 1804-2000 | 较短边分档；0–10 → ±1°；10–50 → ±0°30′；50–120 → ±0°20′（知识库存 arcmin 整数） |
| 螺纹通孔 | GB/T 5277-1985 | 中系列 M3 3.4、M4 4.5、M5 5.5、M6 6.6、M8 9.0、M10 11.0 mm |
| 倒圆/倒角 | GB/T 6403.4（版本待核） | 项目自定子集 0.2…20 mm；不称“优先系列” |
| 表面结构 | GB/T 1031-2009 | Ra 优先系列 0.012…100 µm；GB/T 131-2006 为标注符体系 |

## 术语

- 沉孔 = counterbore（圆柱形）；沉头孔 = countersink（圆锥形）——不可混用。
- 倒圆 fillet；倒角 chamfer；基准 datum；未注公差 general tolerance。

## 约束

- 引用格式：`GB/T 1804-2000 表1，m 级`；无版本/表号不得作为合规结论。
- 钣金、增材、铸件不得直接套用机加工分档。
- 标准正文不复制；只保留摘要、条款定位与数值分档。
