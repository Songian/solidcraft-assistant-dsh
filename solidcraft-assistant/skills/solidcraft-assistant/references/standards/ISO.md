# ISO 标准知识（0.0.1 子集）

来源：`knowledge/standards/ISO.json`。所有条目 `verification.status = unverified`；未经 P3 官方目录核对，**不得**在报告中作为“符合 ISO”的依据。

## 选择

1. 在 brief 写 `intent.standard: "ISO"`；
2. 默认未注线性/角度公差等级 `m`；
3. 投影按第一角（项目约定；ISO 5456-2 允许两种，图面需投影符号）。

## 四类数值规则

| 主题 | 标准 | 关键内容 |
|---|---|---|
| 未注线性公差 | ISO 2768-1:1989 | m 级分档与 GB/T 1804 相同：0.1/0.1/0.2/0.3/0.5/0.8/1.2/2.0 mm |
| 未注角度公差 | ISO 2768-1:1989 | 较短边分档，同 GB 表 |
| 螺纹通孔 | ISO 273:1979 | 中系列 M3 3.4…M10 11.0 mm |
| 表面结构 | ISO 21920:2021 | Ra 优先系列；ISO 21920 取代 ISO 1302，GB/T 131-2006 属 ISO 1302 世代，比较时必须标版本落差 |
| 几何公差 | ISO 1101 / ISO 22081:2021 | ISO 2768-2:1989 已被 ISO 22081 取代；不得再作为现行一般几何公差 |

## 与 GB 的差异

- 线性/角度 m 级：数值相同（eqv）。
- 几何：GB/T 1184 与 ISO 2768-2/ISO 22081 非等同，需逐条核对。
- 表面结构：GB/T 131-2006 对应 ISO 1302:2002，不是 ISO 21920；报告不得写“GB 与 ISO 一致”。

## 约束

- 引用格式：`ISO 2768-1:1989 表1，m 级`。
- 标准正文不复制；只保留摘要、条款定位与数值分档。
- `verified:false` 的条目只能作为“待核对线索”。
